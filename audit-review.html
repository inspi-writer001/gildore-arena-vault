Gildore Vault Audit Review

Date: 2026-07-23

Security score: C

Quality score: B

Ready for mainnet: false

High: agent deletion can strand user funds

delete_agent can close the live IAgent account even though later withdrawal and state access still require that account to exist.

High: initialize can rewrite protocol authority and fees

initialize is idempotent and writable by the hard-coded deployer, so it can rewrite admins, fee basis points, max fee, and fee destination after launch.

Medium: close-trade flag is permissionless

Any caller who knows the accounts can clear ticker.is_in_position, which weakens any monitoring or control flow built on that flag.

Medium: consume_ticker uses panic-style guards and unchecked exponentiation

The amount scaling logic uses 10u64.pow(...) and assert!, which can abort rather than fail cleanly under malformed mint configuration or boundary cases.

Low: signer bump is trusted from stored state on consume path

consume_ticker signs with user_state.bump without re-deriving the canonical bump immediately before CPI.
